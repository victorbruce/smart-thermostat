## 📦 Installing

Clone the repository and run the command:

```sh
git clone https://github.com/victorbruce/smart-thermostat
cd smart-thermostat
```

## 💻 Running the Application

**To start the development server:**

- Install the **Live Server extension**(by Ritwick Dey) in VsCode
- Right-click anywhere in the html code
- Select _Open with Live Server_ from the menu to start the development server

Or

Double click the `index.html` file to open the code in the browser of your choice.

**Running the tests:**

To run the test, run `npm run test`

To get the test coverage, `npm run test-coverage`

## 📋 Approach
The app allows users to:

View and control room-specific air conditioning settings

Adjust temperature presets

Toggle individual or all room ACs

Add custom schedules and preferences via modal input

Experience responsive UI optimized for mobile, tablet, and desktop

Dynamic elements like temperature bars are rendered via JavaScript. Media queries are used to adapt layout (e.g., stacked on mobile, side-by-side containers on tablet and desktop). The JavaScript dynamically creates DOM elements such as .bars based on room configurations and applies corresponding styles and behavior.
